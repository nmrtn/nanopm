## Summary
prawduct is a PM-for-AI-builders skill pack that recently completed a plugin-based distribution migration ("zero committed framework files"), landing in the same convergent architectural space as mycelium and nanopm. Its two-tier learning system is a formalization worth studying.

## What we know
**Distribution model**
Completed migration to plugin-based delivery; no committed framework files in user repos.
- "Plugin migration completed. Moved from file-sync distribution to plugin-based delivery — 'zero committed framework files.'" — competitors.md, 2026-07-01

**Skill namespace**

**Architecture convergence**
